Repository for ERHS 535 homework #5 using R Studio and Github set up. 

Selecting Choice 2, to recreate the graph showing monthly homicides in Baltimore, with a reference for the date of Freddie Gray's arrest. Using color to show winter months (November to April) versus summer months (May to October) and a smooth line to show seasonal trends.

Using Data from https://github.com/washingtonpost/data-homicides (located as csv file in Data folder on this repo).
